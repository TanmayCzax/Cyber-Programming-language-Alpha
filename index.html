Cyber+ Programming Language

A cybersecurity-focused domain-specific programming language designed for security automation and analysis.

About Cyber+

Cyber+ is a domain-specific programming language (DSL) built specifically for cybersecurity tasks such as reconnaissance, scanning, hashing, encoding, and reporting.

Cyber+ source code is written using the .cyp file extension.

Example (.cyp)


create ip = "127.0.0.1";
create port = 80;

Ping(ip);
Scan_Port(ip, port);
Export_Report("json");

Key Features

  • Purpose-built for cybersecurity
  • Readable and minimal syntax
  • Built-in security functions
  • VS Code support
  • Open-source
